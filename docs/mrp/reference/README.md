# Schema tham chiếu ban đầu

`schema_MRP_HTTTDN_17_bang.original.sql` là bản SQL gốc từ bộ tài liệu MRP, giữ nguyên nội dung để đối chiếu.

Ứng dụng khởi tạo từ [schema hiện hành](../schema_MRP_HTTTDN_17_bang.sql), đã cập nhật thông báo thiếu tồn và đơn vị mặc định “cái”. Bản tham chiếu không dùng để khởi tạo runtime hiện tại.
